# Лабораторная работа № 2

Табулирование функций по дисциплине «Компьютерные технологии», вариант 12.

- [main.cpp](main.cpp) — исходный код программы.
- [report.docx](report.docx) — отчёт с условием, блок-схемой, псевдокодом и тестами.
- [lab2.exe](lab2.exe) — готовая программа для Windows x64.

## Запуск

Чтобы запустить готовую программу из PowerShell, откройте папку проекта и выполните:

```powershell
.\lab2.exe
```

Для сборки и запуска в VS Code используйте **Ctrl+Shift+B**. Требуется компилятор `g++` в `PATH`.

Программа по очереди спрашивает `A`, `B` и `N`. Для контрольного примера введите `-3.141592653589793`, `3.141592653589793` и `10`. В дробных числах используйте точку.
