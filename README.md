# Лабораторная работа № 2

Табулирование функций по дисциплине «Компьютерные технологии», вариант 12.

- `main.cpp` — программа на C++.
- `report.docx` — отчёт с блок-схемой, псевдокодом, листингом и тестами.

## Запуск в VS Code

Откройте папку проекта в VS Code. Если в ней есть задача сборки, используйте **Ctrl+Shift+B**. При установленном `g++` можно собрать и запустить программу из терминала PowerShell.

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp -o lab2.exe
.\lab2.exe
```

Нажмите **Enter** для контрольного примера с границами от −π до π и 10 интервалами. Для своих данных введите `A B N` через пробел и используйте точку в дробных числах.
